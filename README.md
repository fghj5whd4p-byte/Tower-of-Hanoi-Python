# Tower of Hanoi - Python

A Python project that solves the Tower of Hanoi problem using recursion.

## Project Description

This project implements the Tower of Hanoi algorithm using a recursive function.

The program allows the user to enter the number of disks, displays the correct sequence of moves required to move all disks from the source rod to the target rod, and calculates the total number of moves.

## Features

- Solves the Tower of Hanoi problem using recursion.
- Accepts the number of disks from the user.
- Displays the correct sequence of disk movements.
- Calculates the total number of moves required.
